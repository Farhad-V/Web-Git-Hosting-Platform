# Backlog item template

- ID and title: to be assigned
- Type: defect / feature / improvement / operational / documentation
- Status: proposed / refined / in progress / blocked / completed
- Responsible role: to be agreed
- Priority, estimate, and schedule: unset until agreed

## Problem and scope

Describe the user, trigger, observed behavior, desired outcome, exclusions, and evidence.

## Acceptance criteria

List observable outcomes and relevant failure/permission cases.

## Dependencies and risks

Record data, security, compatibility, operational, and authorization implications.

## Verification and handoff

Record the implementation commit, review, commands/scenarios, platform, outcomes, skipped checks, documentation, and release status.
