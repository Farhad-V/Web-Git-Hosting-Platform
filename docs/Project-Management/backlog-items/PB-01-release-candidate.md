# PB-01: review the next release candidate

Status: pending release review. Responsible role: project owner/maintainer. Schedule and version: not assigned.

Merged collaboration and UI changes need an explicit candidate review before being published as a new version.

Acceptance criteria:

- Agree the version, scope, and exact candidate commit.
- Complete the [release checklist](../../Releases/v1/RELEASE-CHECKLIST.md).
- Record applicable CI, visual/operational verification, upgrade notes, and limitations.
- Publish only with release authorization and verify tag/commit identity.

Dependencies: current CI, migration/worker guidance, coordinated recovery review, and unresolved candidate defects. No release publication is performed by this backlog record.
