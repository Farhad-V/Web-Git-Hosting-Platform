# PlantUML diagram catalog

All documentation diagrams use editable `.puml` sources stored in their subject folder's `diagrams/` directory. Checked-in SVG previews allow GitHub to display the diagrams without sending sources to an external rendering service.

Historical diagrams retain their original version context; diagram conversion does not declare historical plans implemented.

## Rendering and maintenance

See [rendering instructions](RENDERING.md). Update the source, regenerate its SVG, and review the document link together. The [manifest](manifest.json) maps every diagram to its document and image.
