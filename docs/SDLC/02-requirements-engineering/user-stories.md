# User stories

| Story | User need | Requirements |
| --- | --- | --- |
| US-R01 | As a user, I can authenticate and end my session so access is controlled | RE-F01, RE-S03 |
| US-R02 | As an owner, I can create a repository and set visibility | RE-F02, RE-S01 |
| US-R03 | As an owner, I can use a revocable token with my Git client | RE-F03, RE-F04, RE-S04 |
| US-R04 | As a permitted reader, I can find branches, history, files, and tags | RE-F05, RE-F07 |
| US-R05 | As an owner, I can rename without losing Git storage | RE-F06, RE-N01 |
| US-R06 | As an owner, I can create/select branches without overwriting existing refs | RE-F08, RE-I03 |
| US-R07 | As a permitted participant, I can propose and discuss same-repository changes | RE-F09, RE-S01 |
| US-R08 | As an owner, I can merge only the changes I reviewed | RE-F10, RE-N03 |
| US-R09 | As an owner, I can run/cancel built-in checks and inspect results | RE-F11, RE-I05 |
| US-R10 | As a browser user, I can read the interface in my preferred theme and viewport | RE-F12, RE-N04 |
| US-R11 | As an operator, I can verify health and recover metadata and Git together | RE-N05, RE-I04, RE-D02 |

These stories describe intended current behavior, not automatic release approvals. Test normal, invalid, unauthorized, stale, and interrupted cases where relevant using [acceptance criteria](acceptance-criteria.md). Historical story IDs remain in [the original record](11-user-stories-and-acceptance-criteria.md).
