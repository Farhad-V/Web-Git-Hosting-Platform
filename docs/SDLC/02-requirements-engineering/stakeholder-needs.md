# Stakeholder needs

| Stakeholder | Need | Requirement group |
| --- | --- | --- |
| Repository owner | Reliable hosting, visibility, credentials, history, and controlled merges | RE-F01 to RE-F11, RE-S01 to RE-S05 |
| Permitted signed-in participant | Discover public code and propose/discuss changes without owner authority | RE-F05, RE-F07, RE-F09, RE-S01 |
| Public visitor | Read public content without exposing private repositories | RE-F05, RE-F07, RE-S01 |
| Operator | Observe health, supervise workers, and recover coherent data | RE-I04 to RE-I06, RE-N01, RE-N05, RE-D02 |
| Maintainer | Reproducible implementation, tests, compatibility, and documentation | RE-N06, RE-N07, RE-I07 |
| Project owner/reviewer | Scope integrity, acceptance evidence, and honest release status | RE-N07 and all acceptance criteria |

These roles do not create organization/team permissions. The [stakeholder register](../../Project-Definition/stakeholders-and-external-systems.md) and [current scope](../../Project-Definition/project-scope.md) define context; [user stories](user-stories.md) translate needs into behavior.
