# Project definition overview

GitForge is the Web Git Hosting Platform owned by Farhad Valizadegan. This definition describes the implemented project and its boundaries as of 2026-10-11. The released baseline is v1.0.1; subsequent collaboration and UI changes are merged into main but remain unreleased.
