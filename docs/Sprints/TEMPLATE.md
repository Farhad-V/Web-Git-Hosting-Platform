# Sprint record template

Copy this template into a new descriptive filename. Replace placeholders with confirmed information and leave unknown or pending fields explicit.

## Context

- Dates: to be agreed
- Goal: to be defined
- Branch or pull request: to be identified
- Status: planned / in progress / completed

## Scope and acceptance criteria

List user-visible outcomes, exclusions, dependencies, and measurable completion criteria.

## Delivered changes

Record completed work and link to its requirements, implementation, and documentation. Separate incomplete work from delivered behavior.

## Verification

Record the exact commit, commands or scenarios, platform, outcome, and any skipped or blocked checks. Link to CI results where available.

## Risks and handoff

Document migrations, worker restarts, backup/recovery implications, known limitations, and follow-up backlog items.
